# DueDateTimer
기존 타이머의 방식과 달리, <br>
**마감시간(DueDate)을 입력하면 현재시간에서 자동으로 남은 시간을 계산(Timer)하여 출력**해주는 [웹 페이지](https://duedatetimer.netlify.app/)입니다. <br>

## 📌 프로젝트 설명
- 3분, 5분과 같이 카운트 다운을 진행할 시간을 정확히 알고 있어야 했던 기존의 타이머와 달리, <br>
마감 일자나 시간을 기준으로 자동으로 남은 시간을 계산해서 타이머 형태로 보여주는 Due Date Timer 입니다. <br>
- 타이머 종료 시에, alert 알람 소리와 함께 배경색이 전환되는 동작이 됩니다.
